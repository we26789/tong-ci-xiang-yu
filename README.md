# 同词相遇 · Mind Meld

两个脑洞，一场奇妙相遇。支持**离线同屏**和**邀请码联机**的双人联想游戏。

## 开始游玩

### 离线同屏

双击 `index.html`，两个人在同一块屏幕上玩，无需安装或联网。这个 HTML 包含全部界面、SVG 图形、音效和离线逻辑。

### 本地和局域网联机

需要 Node.js 22 或更高版本，本机实际验证版本为 24.15.0。服务没有第三方运行依赖，不需要先安装 npm 包。

双击 `启动联机.cmd`，或在项目目录执行：

```powershell
npm start
# 等效：node server.cjs
```

终端会显示本机和局域网访问地址。默认端口为 4173，默认监听 `0.0.0.0`。

1. 房主打开本机地址，选择模式和主题，点击「创建房间」。
2. 将生成的**六位邀请码**或**分享链接**发给好友。分享链接会优先使用实际网卡的局域网地址。
3. 好友连接同一网络，直接打开分享链接，点一次「确认加入」。也可先打开局域网首页，点击「输入邀请码」，输入六位代码或粘贴完整链接。
4. 房主是玩家 A，好友是玩家 B。每个人只控制自己的词，双方锁定后可以同步揭晓。

打开分享链接本身不会占位，不会开始计时。每间房最多两人，房间创建后两小时内有效；任一方明确退出会关闭房间。短暂断网会自动重连，刷新会恢复当前浏览器席位和自己已锁定的词。下一轮和再来一局均需双方准备。

局域网链接不能直接发给不同网络的好友使用。其他设备无法连接时，检查同一网络、主机防火墙对 Node.js 的访问许可，以及 Wi-Fi 是否启用了设备隔离。本轮没有自动修改防火墙。

自定义端口：

```powershell
$env:PORT = '58528'
node server.cjs
```

联机房间存在服务进程内存中，服务重启后房间失效。终端关闭会停止服务。

### 未来放到 GitHub

本轮没有创建远程仓库、推送或公网发布。可以把整个项目作为源码上传 GitHub。

**GitHub Pages 只提供静态页面，不能运行这个 Node 房间服务。** 异地联机需要将 `server.cjs` 和前端一起部署到支持 Node 的 HTTPS 服务，再配置真实公网地址：

```powershell
$env:PUBLIC_URL = 'https://你的实际游戏域名'
node server.cjs
```

`PUBLIC_URL` 必须是根路径地址，不含账号、查询参数或片段；公网地址须为 HTTPS。它只控制分享地址与安全 Cookie 配置，设置此变量不会自动部署网站或生成域名。前端与接口保持同源；不需要配置第三方中转或把密钥写入网页。

当前服务采用单进程内存房间；部署时应保持单实例，或先接入共享状态与分布式限速后再扩容。

## 怎么玩

1. 两个人各写一个词。输入会隐藏，写好后各自点击「锁定」，也可按 Enter 锁词。
2. 两人就绪后点击「同时揭晓」，倒数结束，两个词一起出现。
3. 如果不同，下一轮各想一个连接刚才两个词的词。比如「森林」和「海洋」，可能会一起想到「自然」。
4. 在同一轮写出同一个词，就相遇了。轮数越少，默契等级越高。

忽略空格、英文大小写、标点和不可见控制字符后严格判定。意思相近但写法不同不算相遇，每个词最多 10 个字。

- **自由漫游**：不限时，慢慢靠近。
- **限时心跳**：首次输入后，本轮双方同步计时 30 秒。后台或弹窗中仍计时；超时清空未揭晓词，该轮计入成绩，双方准备后继续。
- 六种主题、随机词组、按浏览器本地日期固定的每日灵感；只启发联想，不限制输入。
- 真实回合轨迹、最近 30 次本地相遇记录、各模式最佳成绩、四枚成就。
- 1080 × 1350 PNG 相遇卡、战绩文案复制、邀请文案与链接分享。不支持剪贴板时可手动复制；支持系统分享的浏览器会在用户点击后打开原生分享面板。
- 合成音效开关、键盘操作、移动布局、弹窗焦点管理和「减少动态效果」适配。

等级：1 轮 SSS，2–3 轮 S，4–5 轮 A，6–8 轮 B，其余为 C。成就对应首次相遇、三轮内相遇、三个主题相遇和五次相遇，以最近保留的 30 次记录计算。

## 保存与隐私

离线模式不发送网络请求。联机时，当前局的词通过同源服务同步：**服务器只向本人返回自己的未揭晓词，对方只能看到锁定状态**，直到统一揭晓。联机席位采用 HttpOnly / SameSite Cookie，分享 URL 只有房间码，没有席位凭证。

联机服务不把词或会话凭证写入日志或磁盘，退出和超时会清空未揭晓词。房间到期后短期保留已失效状态以解释邀请错误，随后从内存清理。没有账号、第三方分析或对外分享上传。

已完成战绩仍只保存在当前浏览器 localStorage。旧版 `tcxy.best` 保留为自由模式最佳成绩，两个模式的最佳成绩独立保存。联机刷新可恢复服务端席位；离线局刷新只恢复已揭晓轨迹，不恢复未揭晓词。

清除浏览器数据、换浏览器或改访问地址（例如从 `127.0.0.1` 换成局域网 IP）不会自动迁移本地战绩。浏览器禁止本地存储时仍可玩，关闭后本地战绩可能消失。

## 结构与验证

| 文件 | 内容 |
| --- | --- |
| `index.html` | 完整前端与离线游戏入口 |
| `server.cjs` | HTTP 页面、邀请接口、Cookie、长轮询、限速与重复请求处理 |
| `server/rooms.cjs` | 服务器权威房间、席位、倒数、回合与超时状态 |
| `server/core.cjs` | 复用 HTML 内可信的纯游戏逻辑 |
| `tests/*.test.cjs` | Node 内置核心、房间和 HTTP 测试 |
| `tests/browser-smoke.cjs` | 原同屏玩法、移动布局和导出回归 |
| `tests/online-browser.cjs` | 独立浏览器与实际局域网地址的邀请联机验证 |
| `artifacts/` | 截图、实际导出图片和测试报告 |
| `.backups/` | 本地原版与联机改造前备份，已被 Git 忽略 |

```powershell
npm test
```

浏览器测试使用开发机器已有的 Playwright 和 Microsoft Edge，与游戏运行无关：

```powershell
# Playwright 在 Node 模块查找路径中时：
npm run test:browser
npm run test:online

# 或指定本机已安装的 Playwright 模块目录：
$env:PLAYWRIGHT_MODULE = '本机 Playwright 模块绝对路径'
npm run test:online
```

自动化使用隔离的浏览器环境。本机和实际网卡地址已参与双浏览器验证，但没有用两台物理设备或公网部署进行验收。房间服务器使用标准库，没有需要安装或审计的第三方运行包。
