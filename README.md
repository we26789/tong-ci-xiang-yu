# 同词相遇 · Mind Meld

隔着屏幕，在同一个词里相遇。邀请一位好友，各想一个词，一轮轮联想，直到写下同一个答案。

- [开始双人联机](https://120.77.201.3/tongci/)
- [GitHub Pages 入口](https://we26789.github.io/tong-ci-xiang-yu/)（自动进入联机站点，保留邀请参数）
- [GitHub 源码](https://github.com/we26789/tong-ci-xiang-yu)

作者：**we26789**。希望把「你在想什么」，变成「原来，你也一样」。欢迎页包含玩法、创作初衷与作者介绍；进入房间后，页面只保留当前阶段需要的内容。

## 一起开始

1. 在欢迎页选择自由或限时模式、联想主题，点击「创建房间」。
2. 复制六位邀请码或完整链接发给好友。等待页会显示邀请状态；复制成功后显示「已邀请，等待对方接受」。该状态表示已完成分享操作，不表示对方已经看到。
3. 好友点击「加入房间」，输入完整邀请码或粘贴当前站点的邀请链接，自动配对。直接打开分享链接时，点击「接受邀请，开始游戏」。
4. 好友加入后，双方直接进入对局。创建者为玩家 A，加入者为玩家 B，各自在自己的设备上操作。

每个房间最多两人，创建后两小时内有效。房满、失效或错误的邀请码会显示原因。访问分享链接本身不会占位或开始计时。任一方明确离开会关闭房间；短暂断网自动重连，刷新恢复席位和自己已经锁定的词。

## 怎么玩

对局顶部是两名玩家和状态，中间是词语对比，底部只有本人的文字输入框。

1. 第一轮，各写一个词，写好后点击「锁定词语」，也可以按 Enter。揭晓前可以解锁修改。
2. 两人都锁定后，点击「同时揭晓」。倒数结束，两个词一起出现。
3. 如果不同，下一轮各自想一个能连接上轮两个词的词。例如「森林」与「海洋」，可能会一起想到「自然」。双方点击准备后进入下一轮。
4. 同一轮写下同一个词，就相遇了。结果页展示相遇词、轮数、默契等级、用时和完整轨迹。

**自己的词明文可见，对方的当前词在揭晓前保密。** 这由服务端隔离实现，对方接口也拿不到未揭晓词。后续轮次，中间保留上轮揭晓的两个词供联想，底部显示自己的当前输入。

- **自由漫游**：不限时，慢慢靠近。
- **限时心跳**：首次输入或开始中文选字后，本轮双方同步计时 30 秒；切后台和打开弹窗仍计时。超时清空未揭晓词，该轮计入成绩，双方准备后继续。
- **六种主题**：自由联想、山野自然、人间烟火、日常碎片、脑洞宇宙、浪漫频率。主题提供联想方向，不限制输入。
- 每词最多十个字符。中文拼音选字期间不会被十字限制截断，也不会被好友状态更新覆盖；确认候选词后再限制长度。Enter 选字不会提前锁词。
- 判定忽略空格、英文大小写、标点及不可见控制字符；意思相近但写法不同不算相遇。
- 等级：1 轮 SSS，2–3 轮 S，4–5 轮 A，6–8 轮 B，其余 C。

支持揭晓动画、相遇庆祝、音效开关、键盘操作、弹窗焦点恢复与减少动态效果。手机和桌面使用同一套完整联机流程。

## 分享与档案

相遇后可以：

- 保存 **1080 × 1440 PNG 战绩卡**，包含相遇词、等级、轮数、用时与最近六轮轨迹。
- 复制文字战绩，包含完整回合轨迹和游戏入口。
- 使用系统分享；浏览器不支持时，提供图片预览、保存图片与复制文字。
- 双方同意后在当前房间再来一局，或返回首页。

战绩链接使用游戏首页，不附带房间码或席位凭证。图片在浏览器本地生成，不上传到第三方服务。最近 30 次有效战绩保存在当前浏览器，可从首页「相遇档案」重看每轮词语。

## 本地和局域网运行

需要 Node.js 22 或更高版本。已用 24.15.0 验证。服务只使用 Node 标准库，没有第三方运行依赖，无需安装 npm 包。

双击 `启动联机.cmd`，或在项目目录运行：

```powershell
npm start
```

终端会显示本机和局域网地址。默认监听 `0.0.0.0:4173`。房主在本机创建房间，分享链接会优先采用实际网卡的局域网地址；好友连接同一网络，打开该链接接受邀请即可。邀请码必须在同一台房间服务的首页输入。

更换网络后，局域网 IP 可能变化，需要重新获取链接。局域网链接不能用于异地联机；异地使用上方的 HTTPS 公网地址。无法连接局域网时，检查同网段、系统防火墙的 Node 许可，以及 Wi-Fi 设备隔离。

自定义端口：

```powershell
$env:PORT = '58528'
node server.cjs
```

直接双击 HTML 只展示介绍并提示使用联机入口，不提供同屏或模拟对局。房间保存在服务进程内存中，关闭或重启服务后旧房间失效。

## GitHub 与公网部署

GitHub 保存完整源码。推送 `main` 后，Actions 运行核心、房间隐私、HTTP 和 Pages 构建测试，再发布 Pages。Pages 根据仓库变量 `ONLINE_GAME_URL` 自动进入联机站点，携带原有 `?room=...` 参数，不向 Pages 请求房间接口。

GitHub Pages 提供静态托管，Node 房间服务部署在现有服务器的独立路径 **`/tongci/`**。前端与接口同源，服务器原来的 HTTP / HTTPS 首页仍为协作平台。

```powershell
$env:PUBLIC_URL = 'https://120.77.201.3/tongci/'
node server.cjs
```

`PUBLIC_URL` 控制路由前缀、分享地址与 Cookie 路径，必须是 HTTPS 根地址或以 `/` 结尾的目录地址，不含账号、查询或片段。本地运行不必设置。当前使用单实例内存房间；扩容前需先实现共享状态和分布式限速。

构建静态入口：

```powershell
$env:ONLINE_GAME_URL = 'https://120.77.201.3/tongci/'
npm run build:pages
```

构建只发布 `_site/index.html` 和 `.nojekyll`；服务端源码、备份、环境文件和本机战绩不会进入静态网站。部署、证书与回退见 [deploy/README.md](deploy/README.md)。

## 保存与隐私

席位使用 HttpOnly / SameSite Cookie，公网加 Secure，路径限定为游戏目录。分享 URL 只有房间码。服务器只向本人返回自己的未揭晓词，双方只能提前看到锁定状态。

服务不把词或会话凭证写入日志或磁盘；退出和超时清空未揭晓词。失效房间短期保留状态用于解释错误，随后清理。没有注册、第三方分析或自动对外上传。

已完成战绩只保存在 localStorage，保留旧版有效记录。清除浏览器数据、换设备或更换访问地址不会自动迁移档案；禁止本地存储时仍可完成游戏，记录可能无法保留。未锁定草稿不写入本地存储，刷新后需重新输入。

```powershell
npm test

```

浏览器测试使用开发环境已有的 Playwright 和 Microsoft Edge，与服务运行无关。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块绝对路径，或将其目录加入 `NODE_PATH`。

- `test:ime`：CDP 合成拼音、确认中文、选字中收到好友更新、同步计时与超时清空。
- `test:online`：邀请复制、接受后直接开始、房满、失效、输入校验、粘贴完整链接自动加入、禁止本地存储时完成游戏。
